================================================================================
  🌐 2-網頁發佈包DIST - 使用說明
================================================================================

本資料夾是已經過 Vite 優化編譯的純靜態網頁發佈包（共約 1.4 MB）。

--------------------------------------------------------------------------------
📁 檔案結構：
--------------------------------------------------------------------------------
- index.html        : 網頁主入口
- assets/           : 壓縮後的 JS 與 CSS 資源（已設定相對路徑）
- Lotto3D.exe       : 輕量本地啟動器（雙擊自動以 App 視窗開啟）
- run_dist.bat      : 靜態伺服器批次檔（需電腦有 Node.js）
- server.cjs        : 靜態伺服器腳本

--------------------------------------------------------------------------------
🚀 本地運行方式：
--------------------------------------------------------------------------------
方式 1（最簡單，免 Node.js）：
  直接雙擊資料夾內的「Lotto3D.exe」，會自動啟動本地服務並以獨立視窗開啟。

方式 2（透過 Node.js 啟動）：
  雙擊「run_dist.bat」，會啟動本地伺服器並自動以瀏覽器打開 http://localhost:4173/。

--------------------------------------------------------------------------------
🏢 部署至伺服器：
--------------------------------------------------------------------------------
本資料夾內的所有檔案可直接上傳到任何網頁伺服器（例如 Nginx, Apache, IIS, AWS S3, GitHub Pages）：
- Nginx 範例配置：
    location / {
        root   /path/to/dist;
        index  index.html index.htm;
        try_files $uri $uri/ /index.html;
    }
