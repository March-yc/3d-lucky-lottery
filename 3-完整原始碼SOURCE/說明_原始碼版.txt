================================================================================
  💻 3-完整原始碼SOURCE - 使用與二次開發說明
================================================================================

本資料夾包含本專案所有前端 React 19 與 3D 物理引擎原始代碼。

--------------------------------------------------------------------------------
🛠️ 環境需求：
--------------------------------------------------------------------------------
- 作業系統：Windows / macOS / Linux
- Node.js：推薦 v18.0.0 或 v20.0.0 以上 LTS 版本
  (下載地址: https://nodejs.org/ )

--------------------------------------------------------------------------------
🚀 快速啟動（最簡單）：
--------------------------------------------------------------------------------
Windows 用戶直接雙擊資料夾內的「start.bat」！
- start.bat 會自動檢測 Node.js 環境。
- 若尚未安裝 node_modules，會自動執行 npm install。
- 依賴安裝完成後會自動調用瀏覽器打開 http://localhost:5173/。

--------------------------------------------------------------------------------
⌨️ 手動命令行執行：
--------------------------------------------------------------------------------
1. 開啟終端（Terminal / CMD / PowerShell），進入本資料夾：
   cd 3-完整原始碼SOURCE

2. 安裝依賴（首次執行需執行）：
   npm install

3. 啟動開發伺服器（支援代碼熱更新）：
   npm run dev

4. 打包生產版本：
   npm run build

5. 打包單檔 Windows EXE：
   npm run electron:dist

--------------------------------------------------------------------------------
📁 核心目錄架構：
--------------------------------------------------------------------------------
- src/App.jsx           : 核心主組件（狀態管理、UI介面、中獎名單計算）
- src/components/       : 3D 物理搖獎核心
  - PhysicsLottoMachine.jsx : 玻璃大罐、剛體碰撞、手搖把手、半環形展台平攤
  - StorageJar.jsx          : 右側透明水晶存球罐
  - PrizeRibbon.jsx         : 頂部獎項橫幅
- electron/             : Electron 桌面打包主程序
- 上半年生日名单.xlsx     : 測試用 Excel 名單數據
