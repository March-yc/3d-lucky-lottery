## ✨ 系統核心功能亮點

- **3D 擬真物理碰撞**：大玻璃罐球體內部具備剛體力學重力、反彈與旋風力場，支援空閒沉底、手搖高速狂飆回旋、拍打玻璃彈球彩蛋。
- **球數 1:1 動態實時對應（出來一個少一個）**：
  - 罐內球數嚴格等於當前未中獎人數。
  - 每抽出一位幸運兒，其專屬彩球自罐內脫離並滾入滑道，大罐內的彩球肉眼可見即時少一顆。
- **罐內平攤看剩餘名單（Amphitheater 展台）**：
  - 一鍵將剩餘彩球在玻璃罐內展開為半環形階梯展台，白底徽章正對鏡頭，全場清晰可見剩餘員工工號與姓名。
  - 支援一鍵收攏或直接按住手柄立即開搖。
- **文字 Auto-Fit 智能防溢出**：彩球上的工號與姓名自動測量寬度，2~6 字中文或英文姓名（如 Alexander）均端正居中、永不溢出。
- **右側 3D 榮耀水晶存球罐**：通透晶瑩無暗霧，抽出的彩球凌空拋物線彈跳入罐，自下而上單列階梯展示，切換獎項即刻智能同步對應。
- **盛典榮耀總中獎大榜**：點擊頂部「總名單」可喚起全螢幕榮耀榜，支援依獎項分組、統計徽飾與中獎時間明細。
- **密碼學 CSPRNG 真隨機**：採用操作系統底層硬件熵源，經過 10 萬次蒙地卡羅抽樣實測，卡方檢驗值優良，無作弊偏好、絕對均等。

## 🚀 在其他電腦上運行的完整教學

### 1. 需要安裝什麼？
本系統運行只需要**一個基礎環境**：
- **Node.js**：推薦 LTS 穩定版（**v18.0.0** 或 **v20.0.0 以上**）。
  - 下載地址：[https://nodejs.org/](https://nodejs.org/)
  - 安裝方式：一路點擊「Next」安裝完成即可。

---

### 2. 方式 A：一鍵雙擊啟動（最推薦、最簡單）
專案目錄下已為您內建優化版批次檔 `start.bat`，具備**智能環境檢測**與**自動依賴安裝**：
1. 將整個專案資料夾複製到新電腦。
2. 在資料夾內找到 **`start.bat`**，直接**滑鼠左鍵雙擊**。
3. `start.bat` 會自動執行：
   - 檢查目標電腦是否有 Node.js（若無會提示下載網址）。
   - 檢查是否已有套件依賴（首次運行會自動執行 `npm install`）。
   - 自動調用默認瀏覽器打開 `http://localhost:5173/`。
4. 即可直接在大螢幕或投影機上進行 3D 抽獎！

---

### 3. 方式 B：命令行手動啟動（工程師模式）
若您習慣使用 Terminal / CMD / PowerShell：
```bash
# 1. 進入專案根目錄
cd Lotto2

# 2. 首次運行安裝依賴（僅需執行一次）
npm install

# 3. 啟動開發伺服器
npm run dev
```
啟動完成後，終端會顯示：
```text
  VITE v8.3.0  ready in 150 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```
在瀏覽器打開網址即可。

---

### 4. 方式 C：正式年會高效發佈模式（極致幀率）
在正式年會或大會演講時，如果您希望以**最省 CPU/GPU 資源、最高流暢度（消除開發環境熱更新開銷）**運行：
1. 雙擊專案目錄下的 **`start_production.bat`**。
2. 系統會自動將檔案打包至 `dist/`，並以 Production 模式開啟 `http://localhost:4173/`。

## 📊 自訂名單與獎項導入指南 (Excel)

新電腦拿到後，如何更換為你們公司的名單？

### 步驟 1：準備名單 Excel
系統內置**智能多語系欄位探測器**，您的 Excel（`.xlsx`, `.xls`, `.csv`）表頭支援任意以下格式：
- **工號欄位**：支援 `工号`、`工號`、`员工工号`、`员工编号`、`ID`、`No`、`序号` 等。
- **姓名欄位**：支援 `姓名`、`名字`、`员工姓名`、`員工姓名`、`人员`、`Name`、`Full Name` 等。
- **部門欄位**（可選）：支援 `部门`、`部門`、`组别`、`单位`、`Department` 等。

> 💡 **小撇步**：即使 Excel 表格內完全沒有表頭，系統也會自動以第 1 列當作工號、第 2 列當作姓名智能讀取！

### 步驟 2：在系統中匯入
1. 進入系統，點擊畫面右上角 **⚙️ 設置**。
2. 切換至 **【名单与奖池管理】** 分頁。
3. 點擊 **【选择文件导入】**，選取您的 Excel 檔案。
4. 系統會彈出確認窗：
   - 點擊【確定】：清空先前歷史中獎，全新開抽（推薦）。
   - 點擊【取消】：保留舊中獎記錄。
5. 視窗下方設有 **「当前奖池人员明细表格」**，上傳完成後可立即滾動核對所有姓名與工號！
6. 關閉設置，點擊左側 **「👁️ 平摊看剩余名单」**，大玻璃罐內的球將全部整齊浮現，正面展示每一位員工的名字！

## ❓ 常見問題排查 (FAQ)

### Q1：在新電腦打開後，畫面是黑的或顯示無法連線？
- 請確認是否已執行 `start.bat`，且黑底的終端命令列視窗**沒有被關閉**（該視窗是本地網頁伺服器，抽獎期間需保持開啟）。

### Q2：如何讓手機或平板電腦也能看到畫面（局域網連線）？
- 本系統預設開啟 `--host` 廣播。
- 只要新電腦與手機/平板連接同一個 Wi-Fi，在終端中查看 `Network: http://192.168.x.x:5173/`，用手機瀏覽器輸入該 IP 即可同步瀏覽！

### Q3：不小心抽錯人，或者中獎人不在現場怎麼辦？
- 在中獎大卡片彈出時，右下角設有 **「重抽」** 按鈕。
- 點擊「重抽」後，該中獎記錄會被即時撤銷，彩球自動回補到大球池中，您可以立即重新為該名額抽取下一位！
