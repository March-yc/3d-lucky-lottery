  🏆 3D 物理碰撞幸運搖獎機系統 (Lottery 3D) - 完整交付說明
================================================================================

您好！這是一個為活動、年會、抽獎盛典設計的 3D 擬真物理搖獎機系統。
為了方便您在不同電腦或環境下使用，我們已為您將檔案分好 3 大資料夾：

--------------------------------------------------------------------------------
📁 資料夾目錄導覽（請依您的需求選擇）：
--------------------------------------------------------------------------------

【 1-單檔免安裝EXE 】（⭐ 最推薦！活動現場直接用這個）
  - 適用對象：活動現場工作人員、主持人、行政人員。
  - 特色：完全免裝任何軟體（免裝 Node.js、免聯網、免解壓環境）。
  - 使用方式：
    直接滑鼠雙擊裡面的「3D幸運搖獎機.exe」，立即秒開全螢幕獨立視窗！
    隨身碟一插即用，完全不怕目標電腦沒有開發環境。

【 2-網頁發佈包DIST 】（適合網頁伺服器部署）
  - 適用對象：網管人員、需要放在公司內部網站提供多人瀏覽。
  - 特色：純靜態 Web 網頁（HTML/JS/CSS），僅約 1.4MB。
  - 使用方式：
    可直接放上 Nginx / IIS / Apache 伺服器；
    或在本機雙擊裡面的「Lotto3D.exe」或「run_dist.bat」本地瀏覽。

【 3-完整原始碼SOURCE 】（適合工程師二次開發）
  - 適用對象：前端開發工程師、需要修改樣式或邏輯者。
  - 特色：完整 React 19 + Three.js + Cannon-es 原始專案。
  - 使用方式：
    電腦需安裝 Node.js (推薦 v18 或 v20 以上)，
    直接雙擊「start.bat」即可自動安裝依賴並啟動開發伺服器！

--------------------------------------------------------------------------------
📊 如何匯入您自己的名單 (Excel)：
--------------------------------------------------------------------------------
1. 打開本系統後，點擊畫面右上角「⚙️ 設置」。
2. 切換到「名單與獎池管理」分頁。
3. 點擊「選擇文件導入」，選取您的 Excel 表格（根目錄備有「名單匯入範例_可直接測試.xlsx」供您參考）。
4. 系統支援各類表頭（工號/編號/ID、姓名/Name、部門等），亦可自動識別無表頭表格。
5. 匯入後點擊「確定清空歷史」，即可以全新名單開始抽獎！

--------------------------------------------------------------------------------
🎮 活動現場實用操作秘笈：
--------------------------------------------------------------------------------
- 【長按空白鍵 (Space)】：按住開始高速旋風搖獎、放開後減速懸念出球！
- 【長按 3D 金色把手】：直接用滑鼠或觸控螢幕點住 3D 黃銅搖桿旋轉搖獎。
- 【👁️ 平攤看剩餘名單】：點擊畫面左側按鈕，大罐內的彩球會整齊排成展台階梯，正對鏡頭展示每一位剩餘員工的工號與姓名！
- 【🏆 總名單】：點擊右上角隨時彈出金色全螢幕榮耀榜，查看各獎項得主。
- 【⛶ 全螢幕】：一鍵切換無邊框劇院全螢幕（投放大螢幕必備）。
- 【重抽功能】：若得獎者不在現場，在中獎卡片彈出時點擊右下角「重抽」，球池會自動回補該名額。
